# Unity Legacy: An Amazing Journey

**Unity Legacy: An Amazing Journey** is a time-travel prototype developed under strict time constraints for the official **Unity 20th Anniversary Jam**. The project showcases rapid prototyping workflows, mechanic implementation, and clean code principles under a 48-hour deadline.

---

## Key Features

* **Time-Traversal Architecture:** Designed structural shifts between different graphical and technical eras within a singular gameplay loop.
* **Rapid Prototyping:** Implemented character traversal, platforming logic, and objective checks efficiently using standard C# physics behaviors.
* **FX Integration:** Leveraged particle systems and audio managers to optimize overall game feel within the constrained jam window.

---

## Controls

* ⌨️ **WASD:** Character Movement
* ⏏️ **Spacebar:** Jump Mechanic
